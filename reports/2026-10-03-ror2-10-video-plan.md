## Series formula (lock this in)

| Element | Rule |
| --- | --- |
| Format | Complete run, **no commentary**, start → final boss (Mithrix / DLC boss) |
| Title | `Risk of Rain 2 \| [Survivor] [Difficulty] Full Run (No Commentary)` — game first, survivor second, **≤ 60 chars** |
| Difficulty | Rainstorm for the opener, **Monsoon** as the standard, Eclipse ladder as the finale |
| Splitting | If a run exceeds ~45 min, split into `Part 1` / `Part 2` to protect retention |
| Cold open | First 20–30 s = the best moment (boss kill, huge item stack), then the run from the start |
| Chapters | Always. Item pickups, stage transitions, boss fight, finale |
| Thumbnail | Survivor character + big difficulty text, consistent frame (see below) |

## Thumbnail system (consistent frame)

- **Subject:** the survivor character render on the left third, facing in.
- **Text overlay (≤4 words), bottom-left:** e.g. `COMMANDO` / `MONSOON RUN` stacked, or `FULL RUN`.
- **Difficulty badge:** Rainstorm (blue), Monsoon (orange), Eclipse (purple) — consistent colour coding trains the audience.
- **Background:** the moon / Mithrix silhouette for a recognizable "endgame" cue.
- **Contrast:** darken the gameplay/backdrop, bright survivor + text. Same font and text position on every video.

## Per-video checklist (do for each)

1. Record the full run (batch 2–3 runs per session).
2. Cut a 20–30 s cold open from the best moment.
3. Export; if >45 min, split into parts.
4. Write title from the table; description from the template; tags from the sets.
5. Build the thumbnail using the system above.
6. Add chapters (start at `00:00`, ≥3 chapters).
7. Schedule for the fixed Tue/Sat slot, US/EU afternoon.
8. After 48 h, log CTR + average view duration in `DASHBOARD.md`; after 30 days log views and likes.
